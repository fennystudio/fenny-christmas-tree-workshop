# 毛根聖誕樹 DIY｜聖誕教學簡報

芬妮手作 Fenny Studio。由 `fenny-diy-workshop`（心想事成簡報）複製，保留原第 12 頁的 15 支作品影片，標題改成「一根毛根，能變成什麼樣子？」。

線上簡報：https://fennystudio.github.io/fenny-christmas-tree-workshop/

## 學員直接看某一步
網址加 `#step-1` ～ `#step-6`，例如 `…/fenny-christmas-tree-workshop/#step-3`。總覽頁是 `#steps`。

## 放每一步的照片／影片
1. 檔案放進 `steps/`（影片建議 mp4，直式 9:16）。
2. 打開 `index.html`，找到 `STEP_MEDIA`，把檔名填進對應步驟，例如 `3: 'steps/step3.mp4'`；多個檔用陣列。
3. 留空的步驟會顯示「照片／影片待放」預留框。

## 操作
- ← → 或空白鍵換頁，手機左右滑動
- 步驟頁下方有「上一步／步驟總覽／下一步」
